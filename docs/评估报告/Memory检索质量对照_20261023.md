# Memory 会话记忆 R@5 对照（2026-10-23）

## 结论

- 无记忆 R@5：**0.00%**（0/10）。
- 有记忆 R@5：**30.00%**（3/10）。
- 提升：**+30.00%**（严格命中口径）。
- 3 道严格命中：`M01`、`M02`、`M06`；同一条 top-5 命中的 payload 同时包含实体、指标和期间。
- 1 道近似命中：`M10` 的实体、指标、期间都在 top-5 出现，但分散在不同 hit；严格“同一条证据”口径不通过。
- 7 道未命中里，6 道是实体或指标未进 top-5（`M03/M08/M09` 缺实体，`M04` 实体和指标都缺，`M05/M07` 缺指标），1 道是 `M10` 字段分散。
- 绝对值仍低不是“记忆注入无效”：无记忆组只送“它的净利润呢”这类缺实体追问，0/10 是口径上的预期；注入上一轮后提升到 3/10，剩余缺口主要是检索覆盖与排序。

## 一、口径

- R@5 严格命中：top-5 中至少一条同时包含期望实体与期望指标；配置期间时还要求期间命中。
- `no_memory`：只送本轮追问；`memory`：把上一轮问题拼进检索 query。
- 失败题计入分母；空结果不当作命中，也不隐藏错误。

## 五、边界

- 这是“检索输入注入”对照，不是完整多轮生成对照；它衡量记忆是否把实体/指标带回检索 query。
- 若 memory 组提升但绝对值仍低，应优先查语料覆盖与实体过滤，而不是继续加长 query。
- `M10` 说明“字段都出现”与“同一条证据可核对”是两种口径；本报告采用后者，不把分散命中算过。
- 真实运行依赖 Qdrant + Embedding；Qdrant 不可达时报告保持 [SKIP]。
