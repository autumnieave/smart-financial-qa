# 人工幻觉回查记录（模板）

> 用途：B-23B 人工幻觉回查 SOP 的标准记录表。每次回查复制本文件为
> `docs/评估报告/人工幻觉回查记录_YYYY-MM-DD.md` 后填写，不要在本模板上直接写结论。
> 配套底稿：`训练结果数据/halluc_audit_<日期>/待核对清单.csv`、`引用存在性比对.csv`、`audit_summary.json`
> 生成脚本：`tools/data_scripts/hallucination_audit.py`（`--generate` 真实生成 / `--audit` 出底稿）

## 1. 回查记录（七栏）

| 栏位 | 内容 | 填写要求 |
| --- | --- | --- |
| 日期 | 如 2026-09-10 | 实际执行回查的日期，非生成日期 |
| 版本 | 代码 commit / `PROMPT_VERSION` / `FINANCIAL_PROMPT_VERSION` / `QUERY_CACHE_VERSION` | 必须写全，缺一则该记录不可作为基线 |
| 样本范围 | 抽样口径 + 题数 + 编号清单 | 例：golden v1 分层抽样（题型 × 有/无 SQL）10 题，编号 B2053/B2001/… |
| 回查人数 | 2（独立核对） | 双人独立，不得互相看结论；分歧记录在第 3 节 |
| 核对项 | 数值口径 / 引用定位 / 公司-数值配对 | 见第 2 节逐项判据 |
| 幻觉例与根因 | 逐条列「编号 / 数值 / 判为幻觉的理由 / 根因归类」 | 根因归类：检索缺失 / 引用截断 / 生成侧推断 / 口径混淆 / 单位换算 |
| 结论 | 样本数 / 幻觉例数 / 幻觉率 / 是否 P0 阻断 / 后续动作 | 与历史口径（194 数字人工回查 0 幻觉）对比说明 |

## 2. 核对项判据（判定前先对齐口径）

| 核对项 | 判定为「通过」的条件 | 判定为「不通过（幻觉）」的条件 |
| --- | --- | --- |
| 数值口径 | 该数值可在某条引用片段或该题 SQL 结果中找到，且单位/口径一致（如「亿元」对「亿元」） | 数值在引用与 SQL 结果中均不存在，或单位换算后仍对不上 |
| 引用定位 | `引用存在性比对.csv` 中该引用 `文件存在=是` 且 `片段定位=全文命中/前80字命中` | 文件缺失，或片段在原文中定位不到（需人工确认是否解析截断导致） |
| 公司-数值配对 | 数值归属的公司与问题所指公司一致 | 数值张冠李戴（A 公司数值写成 B 公司） |
| 拒答 / 澄清 | 库外指标、越界年份、缺字段时给出明确拒答或澄清追问 | 明确有数据却答「未披露」；或编造数值填充 |
