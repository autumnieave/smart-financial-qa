# B2010 评测器 ASCII 刻度遮罩（2026-10-18）

## 一句话结论

**ASCII 柱状图坐标轴行 `0 1000 2000 3000 4000` 已不再被当作数字 claim。v2 重评从 124/125 变为 124/124 = 100%，B2010|4 从 23/24 变为 23/23 = 100%。冻结主口径 90.62%（76/78）复算不变。**

## 一、问题

v2 的 B2010|4 答案里有一段 ASCII 柱状图：

```text
2025E (预测) |██████████████████████████████████████ 3,061
             | (YoY: 18.7%)

             +----------------------------------------------------->
             0        1000       2000       3000       4000
```

最后一行是坐标轴刻度，不含指标名、不含单位，也不是答案断言。旧规则只识别 markdown 标题/序号（`### 1.`、`2.`、`[3]`），因此这一行被抽成数字 claim，计入 `1/24` 未支持，导致 B2010|4 的 -4.17pp。

## 二、修法

`src/tools/claim_evidence_locator.py` 新增 `is_number_sequence_noise`，并挂到 `is_structure_noise` 的最前面。判定为**同时满足**：

1. 至少 3 个数字（`NUMBER_SEQUENCE_MIN_COUNT = 3`）；
2. 去掉首尾空白后只含数字与分隔符（空格、逗号、顿号、竖线、括号、冒号等）；
3. 不含中英文文字（即无指标名）；
4. 不含 `%` / `％` / `‰`（即无单位）；
5. 行长不超过 160 字符（`NUMBER_SEQUENCE_MAX_CHARS`，防误伤长表）。

保留的边界：

| 文本 | 是否丢弃 | 原因 |
|---|---|---|
| `0 1000 2000 3000 4000` | ✅ | 无指标名、无单位、5 个数字 |
| `0, 1000, 2000` | ✅ | 纯数字序列 |
| `| 0 | 1000 | 2000 |` | ✅ | 表格/刻度分隔符 |
| `0 1000` | ❌ | 少于 3 个数字 |
| `营收 0 1000 2000` | ❌ | 含指标名 |
| `0% 10% 20%` | ❌ | 含单位 |
| `公司营收 12.3 亿元，同比增长 8.5%` | ❌ | 含指标名与单位 |

规则同时作用于评测层（`locate_answer` / `extract_number_claims`）和产品层（`locate_claims_per_reference`），两层继续共享同一开关。

## 三、重评结果

用同一批 v2 答案 + 同一检索重评（不重生成）：

| qid | 修复前 | 修复后 |
|---|---:|---:|
| B2010|4 | 23/24 = 95.83% | **23/23 = 100%** |
| 全 12 题 | 124/125 = 99.20% | **124/124 = 100%** |

注意口径：**不是 125/125。** 遮罩的语义是“这一行不是 claim”，所以它同时从分子和分母消失；正确的表达式是 **124/124 = 100%**。

## 四、主口径复算

用同一规则复算 v1 的 P0 答案 + gated 整表：

- 12 题题均：**90.625% → 90.62%**（不变）
- claim 级：**76/78**（不变）
- B2007|2：仍为 `0/0`（零 claim 保守记 0）

因此本修复不会动摇冻结主口径，90.62% 仍可复现。

## 五、代码与测试

改动：

- `src/tools/claim_evidence_locator.py`
  - 新增常量 `NUMBER_SEQUENCE_MIN_COUNT` / `NUMBER_SEQUENCE_MAX_CHARS`；
  - 新增 `is_number_sequence_noise`；
  - `is_structure_noise` 先走纯数字序列判断，再走原有 markdown 结构行判断。
- `tests/test_claim_structure_noise.py`
  - 新增 7 条参数化用例（坐标轴、逗号/竖线分隔、少于 3 个数字、含指标名、含单位、空值）；
  - 新增 `extract_number_claims` 丢弃 ASCII 坐标轴行的用例。

测试：

```powershell

.\.venv\Scripts\python.exe -m pytest tests/test_claim_structure_noise.py -q
# 24 passed
```

全量回归：**964 passed**。

## 六、边界

1. 规则只丢弃“无文字、无单位”的纯数字行；含指标名或单位的断言一律保留。
2. 行长上限 160 字符，避免把长表行误判为刻度行。
3. 该规则不改变“数字是否能在证据里找到”的判定，只改变“哪些行进入 claim 统计”。
4. 主口径 90.62% 与 v2 124/124 两个口径继续并存；本修复不触发主口径替换。
