# 覆盖率基线（2026-09-09，B-20）

## 目的
为 B-20「覆盖率基线 + CI 覆盖率门禁」留档：给出当前单测对核心纯逻辑模块的覆盖基线，并据此设定 CI 门禁阈值（不设虚高目标，先守真实基线）。

## 基线口径与数据
- 命令：`pytest tests/ -q --cov=core --cov=tools.sql_guard --cov=tools.sql_validator --cov=pipelines.citation_validator --cov=utils.query_cache --cov-report=term`
- 结果：**717 语句 / 110 未覆盖 = 84.66%**，179 passed（2026-09-09 本地 win32 / Python 3.11）

| 模块 | 语句 | 未覆盖 | 覆盖 |

| core/interfaces.py | 10 | 0 | 100% |
| core/retrievers.py | 120 | 17 | 86% |
| core/rerankers.py | 25 | 2 | 92% |
| core/generators.py | 7 | 2 | 71% |
| core/pipeline.py | 15 | 15 | 0%（未接入的旧链路口，见下） |
| pipelines/citation_validator.py | 155 | 12 | 92% |
| tools/sql_guard.py | 93 | 4 | 96% |
| tools/sql_validator.py | 212 | 43 | 80% |
| utils/query_cache.py | 80 | 15 | 81% |

## 全量参考口径（含 app/agents/pipelines 大文件）
- 命令：`pytest tests/ -q --cov=core --cov=app --cov=tools --cov=utils --cov=agents --cov=pipelines`
- 结果：**2730 语句 / 1295 未覆盖 = 53%**
- 主要拉低项（已知，非本轮范围）：app/api.py 0%、app/schemas.py 0%（待 B-19 API 层自动化补齐）、pipelines/rag_pipeline.py 26%（含大量 LLM 分支，人工回查为主）、utils/helpers.py 0%、agents/planner.py 23%。

## 门禁设定
- CI 命令（.github/workflows/ci.yml）：上述基线命令 + `--cov-report=term-missing --cov-fail-under=80`。
- 理由：门禁覆盖「校验（sql_guard/sql_validator/citation_validator）+ 编排（core 组件）+ 存储（query_cache）」纯逻辑核心，规避 LLM 分支与 Web 入口对覆盖率的稀释；core/pipeline.py 为未接入旧链路口，已在报告中标注，不因它拉低阈值。
- 后续：B-19 落地后可将 app/api.py 纳入门禁口径并逐步上调阈值。
