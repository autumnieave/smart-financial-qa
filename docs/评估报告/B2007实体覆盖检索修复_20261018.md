# B2007|2 实体覆盖检索修复（2026-10-18）

## 一句话结论

**B2007|2 的检索根因已修：top-10 在 `coarse_k=100/200` 完全没有点名主体，实体覆盖审计触发 `retry_table`；扩到 400 后 top-10 同时包含白云山和华润三九，最终 `accept`。** 但端到端答案仍失败——生成时只传子问题、丢掉“999/白云山”上下文，模型改选了云南白药；这是**生成输入**问题，不是检索根因。

## 二、诊断：候选池里有没有点名主体

问题：`分析两家企业收益率差异的原因`；追问上下文：`999与白云山相比，去年收益率最高的是`；点名实体：华润三九、白云山。

| 表级召回深度 | 池内表数 | 池内实体命中 | top-10 是否覆盖点名主体 |
|---:|---:|---:|---|
| 100 | 97 | 6（仅华润三九） | **0/2** |
| 200 | — | 仍无白云山 | **0/2** |
| 400 | 360 | 27（华润三九 + 白云山） | **2/2** |

结论：不是“语料没有”，而是**召回深度不够 + 无实体覆盖审计**。原逻辑在“无指标/期间约束”时直接 `accept`，不会因为 top-10 没有点名主体而重试。

## 三、代码改动

### 3.1 `src/core/evidence_iteration.py`

- 新增 `MISMATCH_ENTITY = "entity_mismatch"`；
- `EvidenceDecision` 新增 `missing_entities` 字段，trace 可记录缺失主体；
- 新增 `_hit_covers_entity`：
  - 读 payload 的 `stockName` / `stockCode`；
  - 6 位查询代码按去前导零形式再比一次（`000538` ↔ `stockCode=538`）；
- 新增 `uncovered_entities`：按查询顺序返回没有被任何候选表覆盖的点名实体；
- `audit_evidence` 在“无候选表”之后、**在“无指标/期间 → accept”之前**插入实体覆盖检查：
  - 有缺失且未超轮数 → `retry_table`，`mismatch_type=entity_mismatch`，`next_coarse_k` 100→200→400；
  - 已超轮数 → `reject_with_reason`，保留 `missing_entities`；
  - 全部覆盖 → 继续走原有指标/期间逻辑（无约束则 `accept`）。

### 3.2 与阶段 5 的 `retry_table` 衔接

`retrieve_with_iteration` 不需要新增分支：它已经把 `audit_evidence` 的 `retry_table` 转成下一轮 `coarse_k/row_k`。B2007|2 的实测轨迹：

```text
round 0: retry_table  entity_mismatch  missing=华润三九,白云山  next_coarse_k=200
round 1: retry_table  entity_mismatch  missing=白云山          next_coarse_k=400
round 2: accept       none             missing=()              top-10 覆盖 2/2
```

## 五、端到端答案：检索已修，生成仍丢上下文

重生成脚本 `eval/a_regenerate_answers.py` 当前把**子问题**而不是 `retrieval_query` 传给生成器：

```python
generator.generate(query=question, contexts=contexts, ...)
# question = "分析两家企业收益率差异的原因"
# retrieval_query = "分析两家企业收益率差异的原因 999与白云山相比，去年收益率最高的是"
```

因此答案是：

> “由于用户问题中未明确指定具体的‘两家企业’，我将选取……华润三九与云南白药进行对比分析。”

它虽然在后面的局限性段落提到了白云山，`audit_entity_coverage` 也判“覆盖通过”，但**主对比对象被替换成云南白药**。这不是检索失败，是生成输入丢上下文。

### 诊断验证：把 `retrieval_query` 喂给生成器

同一批证据、同一模型、只改生成输入：

- 答案开头变为“华润三九（000999.SZ）与白云山（600332.SH）”；
- 2024A ROE：华润三九 **17.3%**，白云山 **7.9%**；
- 归因：华润三九净利增长 18.05%，白云山净利下降 30.1%；
- claim faithfulness：**22/22 supported，1.0**。

这证明检索根因已消除；下一步只需在评测生成侧传 `retrieval_query`（含追问上下文），不需要再改检索。
